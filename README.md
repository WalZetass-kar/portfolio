# Portofolio M Ihwal Maulana

Portofolio kreatif dan interaktif berbasis 3D WebGL oleh **M Ihwal Maulana**, Mahasiswa Manajemen Informatika di Politeknik LP3I Pekanbaru.

## Fitur
- **3D WebGL Scene**: Visualisasi lingkungan 3D interaktif menggunakan Three.js.
- **Scroll-Driven Camera**: Pergerakan kamera dan animasi responsif berdasarkan scroll pengguna.
- **Modern Responsive Design**: Tata letak fleksibel untuk desktop dan mobile dengan tipografi dinamis.
- **Bahasa Indonesia**: Disesuaikan untuk profil profesional di Indonesia.

## Teknologi
- HTML5 & CSS3 Modern
- JavaScript (ES6+)
- Three.js & WebGL

## Menjalankan Secara Lokal
```bash
# Jalankan server lokal
python -m http.server 8000
```
Buka browser di `http://localhost:8000`.
